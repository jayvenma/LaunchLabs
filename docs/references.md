# References

## Purpose

LaunchLab is intended to be an engineering toolkit built on established scientific and aerospace references rather than undocumented equations or internet sources.

Whenever practical, engineering models, physical constants, and numerical methods should reference authoritative publications.

This document lists the primary references used throughout the project.

# Citation Policy

Whenever a new engineering model is implemented:

- Document the primary reference.
- State assumptions.
- Include units.
- Document simplifications.
- Link to the relevant documentation if publicly available.

Whenever practical, equations should reference the section or chapter from which they are derived.

---

# Philosophy

LaunchLab is intended to be educational as well as practical.

Engineering decisions should be traceable to authoritative sources rather than undocumented internet code.

If a model cannot be adequately justified or referenced, it should not be included until sufficient research has been completed.
