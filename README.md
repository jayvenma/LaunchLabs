# LaunchLab

*A professional, open-source spacecraft engineering toolkit built to learn, explore, and engineer.*

---

## Overview

LaunchLab is a long-term engineering software project focused on spacecraft engineering and astronautics. It serves as both an engineering laboratory and a portfolio project, growing alongside my education and career in aerospace engineering.

Rather than attempting to solve every aerospace problem immediately, LaunchLab is built incrementally. Each module introduces a new engineering discipline while emphasizing correctness, documentation, testing, and maintainable software design.

The goal is to build software that is not only functional, but trustworthy enough to be used as an engineering reference.

---

## Project Philosophy

LaunchLab is guided by a few core principles:

* Learn by building.
* Prioritize engineering understanding over feature count.
* Use SI (metric) units throughout the project.
* Document assumptions and engineering equations.
* Write clean, readable, and maintainable code.
* Test numerical algorithms thoroughly.
* Build slowly and correctly rather than quickly.

When an engineering topic is not yet fully understood, development pauses until the underlying theory has been studied.

---

## Scope

LaunchLab focuses on **spacecraft engineering**, not aircraft.

Planned areas of development include:

* Orbital Mechanics
* Rocket Propulsion
* Delta-v Budgeting
* Mission Planning
* Planetary Data
* Spacecraft Power Systems
* Thermal Analysis
* Communications
* Numerical Methods
* Optimization
* Scientific Visualization

The project is intentionally modular so additional engineering disciplines can be added over time.

# Engineering Standards

Throughout the project:

* SI units are used internally.
* Equations are documented whenever practical.
* Engineering references are cited where appropriate.
* Numerical algorithms are validated with tests.
* Assumptions are explicitly stated.
* Readability is preferred over clever implementations.
