# Roadmap

LaunchLab is developed in milestone-based releases. Each milestone represents a significant engineering capability added to the toolkit.

---

## v0.0 — Repository Initialization ✅

Project scaffolding and development environment.

Completed:

- GitHub repository
- Project structure
- GitHub Project & milestones
- Documentation framework
- MIT License
- Initial development environment

---

## v0.1 — Engineering Foundation

Establish the engineering framework that all future modules will rely upon.

Planned features:

- Engineering standards
- SI unit conventions
- Physical constants
- Celestial body database
- Vector mathematics
- Numerical utilities
- Plotting utilities
- Testing framework
- Documentation
- Example programs

---

## v0.2 — Orbital Mechanics

Introduce the first spacecraft engineering capabilities.

Planned features:

- Circular orbits
- Orbital period
- Escape velocity
- Hohmann transfers
- Delta-v calculations

---

## v0.3 — Motor & Propulsion Simulation

Model rocket propulsion systems and vehicle performance.

Planned features:

- Rocket equation
- Stage sizing
- Engine performance
- Mass fractions
- Propulsion utilities

---

## v0.4 — Launch Simulation

Expand LaunchLab into launch vehicle analysis.

Planned features:

- Launch profiles
- Gravity losses
- Atmospheric models
- Launch trajectory simulation

---

## v0.5 — Spacecraft Systems Simulation

Model spacecraft subsystems and mission operations.

Planned features:

- Power systems
- Thermal analysis
- Communications
- Mission utilities

---

Future milestones will continue expanding LaunchLab into a comprehensive spacecraft engineering toolkit.
